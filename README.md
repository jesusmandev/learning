# Proyecto de Juegos Web

Bienvenido a este proyecto que contiene dos juegos desarrollados en HTML, CSS y JavaScript.

## 🎮 Juegos Incluidos

### 1. Piedra, Papel o Tijera
Un clásico juego de estrategia donde compites contra la máquina. Elige piedra, papel o tijera y derrota al oponente con la mejor tirada.

- **Archivo**: `piedrapapeltijera.html`

### 2. Mokepon
Un juego interactivo inspirado en Pokémon donde seleccionas tu personaje y compites en batallas estratégicas contra otros jugadores.

- **Archivo HTML**: `mokepon.html`
- **Archivo JavaScript**: `js/mokepon.js`

## 📁 Estructura del Proyecto

```
programar/
├── codigo.js                 # Código auxiliar
├── mokepon.html             # Página principal del juego Mokepon
├── mokepon.js               # Lógica del juego Mokepon
├── newFile.js               # Archivo adicional
├── pagina.html              # Página general
├── piedrapapeltijera.html   # Juego Piedra, Papel o Tijera
└── js/
    └── mokepon.js           # Script de Mokepon
```

## 🚀 Cómo Usar

1. **Clonar o descargar** el proyecto en tu computadora
2. **Abrir** cualquiera de los archivos `.html` en tu navegador web favorito:
   - Para jugar Piedra, Papel o Tijera: abre `piedrapapeltijera.html`
   - Para jugar Mokepon: abre `mokepon.html`
3. **¡Divertirse!** 🎉

## 💻 Requisitos

- Navegador web moderno (Chrome, Firefox, Safari, Edge, etc.)
- No se requiere instalación de dependencias adicionales

## 📝 Notas

- Los juegos funcionan completamente en el navegador
- No se requiere conexión a internet para jugar
- Los datos se almacenan localmente en el navegador

## 👨‍💻 Tecnologías Utilizadas

- **HTML5** - Estructura del contenido
- **CSS** - Estilos y diseño
- **JavaScript** - Lógica de los juegos
